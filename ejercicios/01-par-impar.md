
# Ejercicio 1: Par o impar

## Problema
Determinar si un número entero es par o impar.

## Entrada
Un número entero.

## Proceso
1. Solicitar un número entero.
2. Dividir el número entre 2.
3. Si el residuo es 0, mostrar "Par".
4. En caso contrario, mostrar "Impar".

## Pseudocódigo

Inicio
  Leer numero
  Si numero MOD 2 = 0 Entonces
    Escribir "Par"
  SiNo
    Escribir "Impar"
  FinSi
Fin

## Salida
Indicar si el número es par o impar.

## Pruebas


| Entrada | Resultado esperado |
|---|---|
| 8 | Par |
| 7 | Impar |
| 0 | Par |
| -4 | Par |
