
# Lógica computacional

## Propósito
Practicar algoritmos, operadores lógicos y organización de archivos en GitHub.

## Autor
a395163-commits

## Ejercicios
1. Identificar si un número es par o impar.
2. Construir una tabla de verdad de AND.
3. Resolver una condición de aprobación.

## Herramientas
- Pseudocódigo.
- GitHub.

## Lo que aprendí

- Un repositorio sirve para organizar y guardar los archivos de un proyecto.
- Un commit sirve para registrar los cambios realizados en los archivos.
- Una rama sirve para trabajar en modificaciones sin afectar el proyecto principal.
